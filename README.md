# PDF-LIB Generator & Document Modification Demo

[![JavaScript](https://img.shields.io/badge/JavaScript-ES6-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](https://developer.mozilla.org/)
[![PDF-LIB](https://img.shields.io/badge/Library-PDF--LIB-red?style=flat-square)](https://pdf-lib.js.org/)

> Technical demonstration and utility scripts highlighting programmatic client-side PDF document generation, text insertion, vector drawing, and page merging using PDF-LIB.

---

## Capabilities

- **Client-Side Generation:** Generate clean, vector-rendered PDF documents entirely in the browser without server dependencies.
- **Page Manipulation:** Merge multi-page documents, reorder sheets, and extract targeted sections.
- **Font & Asset Embedding:** Embed standard fonts, custom vectors, and PNG/JPEG graphic assets.

---

## Usage

```bash
git clone https://github.com/mesumali-dev/pdf-lib-generator-demo.git
cd pdf-lib-generator-demo
```
